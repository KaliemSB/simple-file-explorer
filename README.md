# 🗂️ File Explorer for Linux – To-Do List

A simple and functional file explorer for Linux. Below is a checklist of all key features required for usability and completeness.

---

## ✅ Core Functionality

- [ ] List files and directories
- [ ] Navigate into folders and go back
- [ ] View file properties (name, size, type, modified date, permissions)
- [ ] Open files with the default system application
- [ ] Refresh current view

---

## 📁 File and Folder Operations

- [ ] Create new file/folder
- [ ] Rename files and folders
- [ ] Delete files and folders (with confirmation)
- [ ] Move items (cut/paste or drag-and-drop)
- [ ] Copy items
- [ ] Toggle visibility of hidden files (`.dotfiles`)

---

## 🧭 Navigation & UI

- [ ] Breadcrumb navigation
- [ ] Back / Forward buttons
- [ ] Current path bar (clickable or editable)
- [ ] Keyboard navigation (arrows, Enter, Backspace)
- [ ] Right-click context menu (Open, Rename, Delete, Properties, etc.)

---

## 🔍 Search and Filtering

- [ ] Search by file/folder name
- [ ] Filter by type or extension
- [ ] Sort by name, date, size, or type

---

## 🧩 System Integration

- [ ] Detect mounted drives and partitions
- [ ] Show and edit file permissions (chmod/chown)
- [ ] Move to Trash instead of permanent delete
- [ ] Handle symlinks and shortcuts

---

## 🧰 Advanced Features (Optional for MVP)

- [ ] Tabbed browsing or split view
- [ ] File preview (text, images, etc.)
- [ ] Drag and drop between panes or windows
- [ ] Dark/light theme support
- [ ] Bookmarks or favorites panel
- [ ] Compression/extraction (ZIP, TAR, etc.)

---

## ⚙️ Configuration & Persistence

- [ ] Remember last opened folder
- [ ] Config file for settings (e.g., JSON or YAML)
- [ ] Customizable shortcuts and key bindings

---

## 🧪 Performance & Testing

- [ ] Efficient handling of large folders (virtual scrolling, lazy loading)
- [ ] Graceful error handling (permission denied, IO errors, etc.)
- [ ] Loading/progress states for heavy operations

---

Feel free to fork, contribute or customize the feature set depending on your goals.
